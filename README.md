# ESP32 AI 모델 및 코드

## 파일 구조

### 1. esp32_code
esp32 보드에 사용되는 코드를 저장.

### 2. firmware
esp 프로젝트를 빌드 후 나온 bin 파일을 저장.
그래서 빌드의 시간을 줄인다.

### 3. models
모델의 bin파일을 저장한다.
default 버전과 유저가 올린 파일을 여기로 가지고 온다.

### 4. pc
모델을 학습한 코드를 저장.
코랩에서 학습하며 학습이 완료된 bin 파일을 models폴더로 이동시킨다.

### 5. rpi
라즈베리파이 보드에서 실행할 명령어를 쉘로 저장.
